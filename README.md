## Retail Sales Analysis using MySQL and Power BI
Project Overview -
This is an individual data analytics project focused on analysing retail sales data using MySQL and Microsoft Power BI.

Tools Used-
MySQL
MySQL Workbench
Microsoft Power BI
SQL

Project Objectives-
Analyse overall retail sales performance.
Identify top-performing products and customers.
Evaluate sales trends across years and months.
Analyse sales across different countries and channels.
Compare actual sales against budget targets.

SQL Concepts Used -
SELECT, WHERE and GROUP BY
Joins
Common Table Expressions (CTEs)
Window Functions
LAG()
Aggregate Functions
Year-over-Year and Month-over-Month Analysis

Dashboard-
An interactive Power BI dashboard was developed to visualise sales performance, customer contributions, product trends, regional performance and budget comparisons.

Project Type-
Individual Data Analytics Project.
